# Dịch Truyện

App Android dịch màn hình app đọc truyện tranh (Anh / Trung / Nhật / Hàn → Tiếng Việt), lướt đến đâu dịch đến đó, chạy offline.

**Tải APK:** https://github.com/ducbui2k5-hash/DichTruyen/releases/latest/download/DichTruyen.apk

## Cách dùng
1. Cài APK, mở app, chọn ngôn ngữ truyện.
2. Bấm Cấp quyền hiển thị → bật cho Dịch Truyện.
3. Bấm BẮT ĐẦU DỊCH (lần đầu cần mạng để tải gói dịch ~30MB).
4. Chọn Toàn bộ màn hình → Bắt đầu.
5. Mở app đọc truyện và lướt. Dừng tay ~0,5 giây là bản dịch hiện ra.

Bong bóng nổi: chạm = bật/tắt • kéo = di chuyển • giữ lâu = mở cài đặt.
